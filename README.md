# Simulador patrimonial

Aplicação estática educativa. Não há dependências, compilação ou comando de desenvolvimento próprio: abra index.html em um navegador moderno. Os scripts são JavaScript clássico carregado com defer.

O armazenamento local em URLs file:// varia por navegador. Os registros ficam na origem e no dispositivo atuais; não há sincronização, backup ou confirmação institucional. A interface informa indisponibilidade ou falha de gravação.

A aplicação implementa projeção mensal, comparação entre recursos próprios e patrimônio, gráfico SVG com tabela, meta pedagógica baseada nas cotas FII finais, registros manuais separados e conteúdo educativo. Custos, impostos, cupons, vencimento, marcação a mercado e títulos específicos não são modelados.

DEC-022 mantém RF-010/exportação adiado. Não há interface de exportação/importação, autenticação, integração externa, edição ou exclusão de registros. Resultados dependem das premissas, não garantem rentabilidade e não recomendam ativos.
